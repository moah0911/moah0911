#### 2. [Rack — Medical Document Processing Assistant](https://github.com/moah0911/Rack)
`Python · Strands Agents · Amazon Bedrock (Claude) · NLM APIs`
- CLI that extracts clinical PDFs/images/text → links Diagnoses→ICD-10, Meds→RxNorm, Procedures→SNOMED CT with confidence scores
- NLM Clinical Tables + RxNav + Snowstorm with Bedrock fallback, PyPDF fallback for text PDFs

#### 3. [Sick — Self-Improving Coding Agent](https://github.com/moah0911/sick)
`Python · NVIDIA OO-Agents · TUI`
- Object-oriented coding agent that reads/writes/edits code and modifies its own source to improve over time
- `@file` attachments, `!cmd` shell integration, sandboxed bash, experience memory in `~/.sick`

#### 4. [Vision — Privacy-Preserving Browser Agent](https://github.com/moah0911/Vision)
`TypeScript · WebGPU · Transformers.js · FastAPI`
- On-device Vision Transformer reads screen state, redacts PII (faces, passwords, emails, cards, Aadhaar/PAN), sends only sanitized context to server

#### 5. [BudgetWise — AI Expense Forecasting Tool](https://github.com/moah0911/BudgetWise-AI-based-Expense-Forecasting-Tool)
`Python · XGBoost · LSTM · N-BEATS · Streamlit`
- Benchmarked 11 models across 4 families on 30K+ records (5 metrics: MAE, RMSE, MAPE, R², directional accuracy)
- 200+ engineered features, fuzzy merchant matching, 1–30 day forecasts with confidence intervals + anomaly detection — built at Infosys Springboard

#### 6. [Ignisengine — Multi-Agent PRD Generator](https://github.com/moah0911/Ignisengine)
`Python · Gemini 2.0 Flash · Flask · Supabase · CrewAI / LangGraph`
